### 1. Оптимизация структуры проекта
- Компоненты разделены по **feature-based структуре**:
  - `user` → управление данными пользователя  
  - `products` → отображение списка товаров  
  - `cart` → логика корзины
- Контейнеры для работы с Redux (`HeaderContainer`, `ProductsContainer`, `CartContainer`)  
- Разделение **логики отображения** и **управления состоянием**

### 2. Исправление антипаттернов
- Убраны дублирующиеся расчёты состояния корзины (`cartCount`, `totalPrice`)  
- Глобальное состояние хранится в **Redux**, локальные состояния минимизированы  
- Упрощена работа с массивами и объектами в state  

### 3. Оптимизация ререндеров
- Использованы `React.memo` и `useMemo` для снижения ненужных перерендеров  
- Локальные состояния минимально влияют на глобальное состояние Redux

### 4. Стилизация и адаптивность
- Стили CSS восстановлены, но разделены от логики компонентов  
- Адаптивный дизайн для мобильных и десктопных устройств  
- Каждый компонент имеет свои классы, что облегчает поддержку

### 5. Redux Toolkit
- Централизованное управление данными: товары, корзина, пользователь, загрузка  
- Actions и Reducers переписаны для **единообразного обновления состояния**  
- Обновление корзины (добавление, удаление, изменение количества) оптимизировано

### 6. Поддерживаемость
- Код разделен на модули, каждый выполняет **одну задачу**  
- Упрощена читаемость и возможность добавления новых функций  
- Структура и комментарии облегчают поддержку проекта

---

## Инструкции по запуску

1. Установите зависимости:
```bash
npm install
```

2. Запустите проект:
```bash
npm run dev
```

3. Откройте браузер по адресу `http://localhost:5173`
